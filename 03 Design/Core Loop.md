# Core Loop (Draft)

```
   YOUR ISLAND (safe)                      THE WARZONE (risky)
   build · farm · craft · automate   ⇄     fight · loot · escape
          ▲                                       │
          └──── bring rare loot home to craft ◄───┘
                better gear, machines, upgrades
```

- **Island loop (minutes to days):** gather → craft → expand → automate → earn while offline.
- **Warzone loop (one session):** gear up → drop in → loot → survive → extract.
- **Link:** the best materials/blueprints only come from the Warzone; the best gear only comes from crafting on your island.
