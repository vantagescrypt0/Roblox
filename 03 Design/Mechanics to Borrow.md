# Mechanics to Borrow (Draft)
Ideas from [[Islands (Roblox)]] and [[Skybounds (Minecraft)]], adapted for our game. We borrow the *idea* only, never names, numbers or assets.
All of these are [Inference] or [Speculation]; none are decided. Mark each **Yes / Maybe / No**.

## Island side
| Idea | From | How it fits us | Yes/Maybe/No |
|---|---|---|---|
| Passive generators that cost coins, with a range limit so layout matters | Islands totems | Coin sink + "always growing" ([[Design Pillars]] #2) | |
| Leave a few resources manual-only early, then automate them through an expensive late machine | Islands wood | Keeps active play meaningful | |
| Conveyor logic pieces (splitter, filter, sensor) | Islands | Base-building becomes a puzzle people redesign for hours | |
| NPC visits at milestones with a starter pack of the next system | Islands | Teaches without walls of text; good for young players | |
| Hidden collection pieces across zones that complete a trophy | Islands fossils | Gives explorers a goal | |
| Item leveling: gear grows the more you use it | Skybounds | You get attached to a weapon; good with loot heads (losing it hurts) | |

## Warzone side
| Idea | From | How it fits us | Yes/Maybe/No |
|---|---|---|---|
| **Loot head on death** | Skybounds | **Decided.** See [[Warzone]] | Yes |
| Warzone-only materials/keys that unlock the next island tier | Islands keys + [[Core Loop]] | Makes the Warzone the bridge to island progress | |
| Token-summoned bosses with a cooldown, on public servers | Islands bosses | Clear progress bar; pushes players to team up | |
| Ultra-rare cosmetic/pet drops from Warzone bosses | Islands pets | Endgame reason to keep raiding (must be earned, not bought; see [[Monetization Principles]]) | |
| Temporary power you can trade (like fly tokens) | Skybounds | Turns a convenience into an economy item | |
| Several Warzone maps/worlds, rotated by season | Skybounds | Matches [[Anti-Burnout Ideas]] seasonal maps | |

## Economy and social
| Idea | From | How it fits us | Yes/Maybe/No |
|---|---|---|---|
| Player shops on your island, unlocked by a skill level | Islands vending | Shop ownership feels earned; slows alt-account abuse | |
| Direct trades with two-step confirm | Islands handshake | See [[Anti-Burnout Ideas]] anti-scam UI | |
| Daily challenges + island leaderboard | Skybounds | Reason to log in; social status | |
| Limited event items that become status symbols | Islands | Drives trading; bring them back later so it isn't FOMO pressure | |

## Hard lesson
- [Unverified] Islands reportedly had to almost entirely shut down trading after a duplication exploit. **Rule for us:** all trades, loot-head pickups and inventory changes are handled by the server and are all-or-nothing (atomic) from day one. Loot heads are a new place where duplication could happen: two players grabbing the same item at once must never both get it.
